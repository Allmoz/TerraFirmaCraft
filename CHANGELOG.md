### Changes
- Added climbing ropes
  - Crafted from jute fibers, these can be attached to a stalagmite or a Steel Rope Anchor and then thrown over edges
  - The length of the thrown rope is based on the amount of rope items in your hand
- Added support for using fire starters in VR mode when using Vivecraft

### Fixes
- Fix a crash when attempting to place shelf blocks vertically
- Make snow and other block slowdown apply only to living entities (Snow etc. no longer slows thrown items)
